# CasicMesBot (Golang Edition)

Высокопроизводительный приватный бот на Go для быстрой замены сообщений в каналах.

## Фишки
- **Невероятная скорость**: Использует паттерн Worker Pool (горутины) для параллельной замены постов.
- **Обход лимитов**: Сам понимает `retry_after` (FloodWait) и безопасно ждет.
- **Премиум-эмодзи**: Идеально парсит и пересчитывает UTF-16 оффсеты, так что `custom_emoji_id` никогда не слетают.
- **Белый список**: Чужие не смогут пользоваться. Вы (Owner) одобряете заявки через удобные кнопки.
- **Локальная база**: Вся статистика и пользователи хранятся в одном файле `bot.db` (SQLite3). Никаких сложных серверов.

---

## 🛠 Как установить это на свой VPS (Linux / Ubuntu)

Если вы никогда не запускали скрипты на сервере, просто скопируйте эти команды в терминал:

### 1. Установите язык Golang
```bash
sudo apt update
sudo apt install -y golang sqlite3 gcc
```

### 2. Загрузите файлы бота
Скопируйте эту папку (`CasicMesBot`) к себе на сервер (например, через FileZilla, `scp` или `git clone`).
Затем перейдите в неё:
```bash
cd /root/CasicMesBot
```

### 3. Скомпилируйте бота
Эта команда скачает все библиотеки и соберет бота в один файл:
```bash
go mod tidy
go build -o bot_app ./cmd/bot/main.go
```
После этого у вас появится зеленый файлик `bot_app`. Это и есть ваш бот!

### 4. Запустите бота
Запустите бота, указав токен вашего бота (взять у @BotFather):
```bash
export BOT_TOKEN="ВАШ_ТОКЕН_ЗДЕСЬ"
./bot_app
```

*Секрет для новичков*: Если вы закроете терминал, бот выключится. Чтобы он работал 24/7, используйте `tmux`:
1. Напишите `tmux` и нажмите Enter (откроется новое "окно").
2. Запустите бота: `export BOT_TOKEN="..." && ./bot_app`.
3. Нажмите на клавиатуре `Ctrl+b`, отпустите, и сразу нажмите `d`. Вы выйдете из экрана, а бот продолжит работать вечно!
